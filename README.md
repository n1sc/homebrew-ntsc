# homebrew-ntsc

Homebrew tap for [ntsc](https://github.com/n1sc/ntsc) — the Neutron Type-Safe
Compiler: a statically typed, memory-safe systems language compiled through
LLVM.

```sh
brew install n1sc/ntsc/ntsc
```

`Formula/ntsc.rb` is generated and pushed by the release workflow in
[n1sc/ntsc](https://github.com/n1sc/ntsc) whenever a `v*` tag is pushed. Edit it
there, not here.

The formula installs the self-contained macOS tarball (bundled LLVM and
runtime), for both Apple Silicon and Intel.
